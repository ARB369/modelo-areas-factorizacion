¿Cómo funciona?

El modelo representa el polinomio como una suma de áreas: a² + pa + q.

Para formar un rectángulo con binomios de términos enteros positivos se buscan dos enteros positivos m y n tales que m · n = q y m + n = p.

Cuando existen, la factorización es (a + m)(a + n). Si no existen, la simulación indica que no se puede obtener esa factorización mediante este modelo con términos enteros positivos.
